# 星途练习生：Stellar Drift

大型男团选秀题材 · 互动剧情游戏（纯前端 / 静态网页）。

> 一百个少年，一个舞台，七分之一的光。
> 你是被推上王座的那个人——临时队长。

## 玩法

- 你扮演选秀节目《星途练习生》中被导师江慕白钦点的**临时队长**，与七位成员走过 12 周赛程、成团夜与团综季。
- **42 章主线 + 序章 · 约 12 万字**文学剧本 · **8 条结局线**（7 条个人线 + 1 条团体真结局）。
- 主角名可自定义（默认「江晚」），第二人称叙事。

### 角色
| 成员 | 定位 | 声口 |
|---|---|---|
| 林墨轩 | 主唱 | 「别拖了节奏。其余的，交给我。」|
| 温以恒 | 副队长 | 「早餐在锅里，先吃饭，再谈训练。」|
| 顾知遥 | 门面 | 「队长大人，你行不行啊？」|
| 沈时雨 | 主舞 | 「我……可以再练一遍吗？」|
| 苏景行 | 全能ACE | 「小队长，往这儿看——嗯，这样就很好。」|
| 陆清越 | 忙内 | 「今天也要加油哦！」|
| 江慕白 | 制作人·导师 | 「我对你的严格，是因为你值得。」|

## 系统

- **心动值**：7 位角色独立数值，选项即时反馈（右上角 toast + 面板）
- **微博热搜**：黑热搜、屠榜、澄清等剧情节点以热搜榜形式呈现
- **直播弹幕**：舞台/直播场景滚动弹幕（固定 7 条/场）
- **手机消息**：一对一群聊与七人群聊界面
- **成员日记**：第一人称日记，作为剧情旁支视角
- **星轨图鉴**：章节回看 + 结局收集进度
- **本地自动存档**：进度实时存 localStorage，标题页可续玩

## 操作

- 点击画面 / 空格 / 回车：推进剧情
- 顶栏 ♡：心动值面板；☰：菜单（保存 / 图鉴 / 回标题栏）
- 结局由**心动值最高者**决定；若 `stay_together` 旗标成立且七人羁绊均衡，则进入真结局

## 结构

```
stellar-drift/
├── index.html          入口
├── style.css           样式
├── engine.js           引擎（节点播放 / 系统弹层 / 存档 / 图鉴）
├── build.py            合并 data/ch*.js -> data/ch.js
├── docs/
│   ├── OUTLINE.md      42 章总纲
│   ├── CHARACTERS.md   角色圣经
│   ├── STYLE.md        文风锚点
│   └── FORMAT.md       节点数据格式规范
├── data/
│   ├── characters.js   角色数据 + 初始心动值
│   ├── ch01..ch42.js   42 章剧本（每章一个文件）
│   └── ch.js           由 build.py 合并生成
└── assets/img/         7 张角色立绘
```

## 技术

原生 HTML/CSS/JS，无依赖、无构建工具。

本地预览：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

修改剧本后重新合并：

```bash
python build.py
```

## 内容边界

全年龄向。剧本为文学化的情感张力写作，亲密内容止于拥抱、牵手与留白；无露骨性描写。
