# 文风锚点（STYLE.md）——每一段文字过此检查

## 叙述温度
克制抒情（restrained lyricism）。不煽情、不解释心理、不说教。情绪藏在动作、物件、光线和声音里。
- ✅ "他把伞塞进你怀里，转身走进雨里，肩膀很快洇深了一片。"
- ❌ "他心里很难过，因为他一直喜欢着你。"

## 人称与视角
第二人称"你"=玩家（队长）。成员用第三人称。玩家内心可写感受/下意识反应，重大决定交给选项。

## 句子节奏
长短交替型。日常段可舒缓绵长；舞台、冲突、转折用短句急促。每个场景至少一处"呼吸"式短段（一句成段）。

## 对白
口语化、潜台词密度高。每个人物声口严格按角色圣经：
- 林墨轩：短句、零语气词、专业术语自然出现。
- 温以恒：轻、软、常用问句收尾（"还好吗？"）。
- 顾知遥：反问与傲娇句式（"哼""本少爷""才不是"）。
- 沈时雨：低声、迟疑、省略号；紧张时句子破碎。
- 苏景行：懒洋洋、情话与玩笑无缝切换。
- 陆清越：感叹号、叠词、直白的告白式表达。
- 江慕白：判词式短句，冷静低沉，偶用反问施压。

## 场景写作
- 感官锚定：每个场景至少两种感官（声音/气味/温度/触感/光线）。
- 首次登场的角色/场景/道具必须有外貌或外观描写。
- 场景切换用一句过渡文（时间/光线/声音的变化），禁止硬跳。
- 禁止心理直述（"他意识到""其实是"）；禁止 HTML/emoji 滥用（弹幕与微博条目内可有节制使用）。

## 系统文本风格
- 弹幕：饭圈真实语感，7条一组，可带 emoji 与粉号（如"苏苏的小甜饼🍪"）。
- 热搜：#话题# + 热度值，正反面话题都要有（黑热搜也是剧情工具）。
- 手机消息：符合各角色线上聊天风格（苏景行爱发表情包/语音暗示；顾知遥句句傲娇；沈时雨打字慢、措辞斟酌）。
- 日记：第一人称，本人最私密的声音，可透露对玩家未说出口的心事（每篇150-300字）。

## 选择项书写铁律
- 说话写台词加引号，动作直接写动作。禁止"说XXX""问XXX"。
- 选项中不得出现玩家此刻尚未获知的信息（人名、概念、伏笔）。
- 每个选择后必须有 1-2 句铺垫语 + 针对该选择的即时回响文本。

## 禁区（零容忍）
- 任何露骨性描写；未成年角色（陆清越18岁）的任何亲密越界描写（他的线止于纯真浪漫）。
- 心理描写直述、说教、强行催泪、用"他们聊了一会儿"概括对话。
- 成员之间暧昧。
